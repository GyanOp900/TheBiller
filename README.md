# TheBiller
'TheBiller' is a sleek, modern desktop billing application tailored for small retail stores, kiosks, and general shops. Built with Python and PyQt6, it offers an intuitive and user-friendly experience with powerful features to streamline product sales, customer invoicing, and inventory control.

# How To Use

All products and product variables are in the products.json file! You can change certain variables from directly from the file or internal gui options are given inside the app!

The stock system is a little buggy (very buggy) but usable certain features are missing but currently all visible features are working!

All Potential Invoice Variables can be edited in the settings file or through the settings menu(top left corner) in the app.

When QR code is created it generates a png image and stores it until a new one is created!

It's completely safe no network required.

The payment system is based on the Indian UPI Scan to Pay System. Its only a link which is later edited thorugh given variables.
